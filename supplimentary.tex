\subsection{Deep Learning Models (PyTorch 2.0)}

All deep models share the following training procedure:

\textbf{Optimizer:} \texttt{torch.optim.Adam(learning\_rate=0.001, betas=(0.9, 0.999), eps=1e-8)}

\textbf{Loss:} \texttt{torch.nn.BCEWithLogitsLoss()} for binary classification

\textbf{Batch size:} 64

\textbf{Validation:} 10\% of training set; early stopping with patience=20 epochs if validation loss does not improve

\textbf{Epochs:} 20 for large datasets (ApacheJIT, city\_hour); 10 for small datasets (PROMISE)

\textbf{Feature preprocessing:} StandardScaler(). Fitted on training set, applied to test set.

\textbf{Device:} NVIDIA GPU (CUDA 12.0); fallback to CPU if unavailable.

\subsubsection{Simple MLP}
\begin{verbatim}
class SimpleMLP(nn.Module):
    def __init__(self, input_dim):
        super().__init__()
        self.fc1 = nn.Linear(input_dim, 128)
        self.dropout1 = nn.Dropout(0.2)
        self.fc2 = nn.Linear(128, 64)
        self.dropout2 = nn.Dropout(0.2)
        self.fc3 = nn.Linear(64, 32)
        self.dropout3 = nn.Dropout(0.2)
        self.fc_out = nn.Linear(32, 1)
        
    def forward(self, x):
        x = F.relu(self.fc1(x))
        x = self.dropout1(x)
        x = F.relu(self.fc2(x))
        x = self.dropout2(x)
        x = F.relu(self.fc3(x))
        x = self.dropout3(x)
        x = self.fc_out(x)
        return x
\end{verbatim}

\subsubsection{Residual MLP}
\begin{verbatim}
class ResidualMLP(nn.Module):
    def __init__(self, input_dim):
        super().__init__()
        self.fc_in = nn.Linear(input_dim, 128)
        self.residual_blocks = nn.ModuleList([
            ResidualBlock(128) for _ in range(4)
        ])
        self.fc_out = nn.Linear(128, 1)
        
    def forward(self, x):
        x = self.fc_in(x)
        for block in self.residual_blocks:
            x = block(x)
        x = self.fc_out(x)
        return x

class ResidualBlock(nn.Module):
    def __init__(self, dim):
        super().__init__()
        self.fc = nn.Linear(dim, dim)
        self.dropout = nn.Dropout(0.2)
        
    def forward(self, x):
        return x + F.relu(self.dropout(self.fc(F.relu(x))))
\end{verbatim}

\subsubsection{FT-Transformer-Style Model}
\begin{verbatim}
class FTTransformer(nn.Module):
    def __init__(self, input_dim, embed_dim=64, num_heads=8, num_layers=4):
        super().__init__()
        self.embed = nn.Linear(input_dim, embed_dim)
        encoder_layer = nn.TransformerEncoderLayer(
            d_model=embed_dim, nhead=num_heads, dim_feedforward=256,
            batch_first=True, dropout=0.2
        )
        self.transformer = nn.TransformerEncoder(encoder_layer, num_layers=num_layers)
        self.fc = nn.Sequential(
            nn.Linear(embed_dim, 64),
            nn.ReLU(),
            nn.Linear(64, 1)
        )
        
    def forward(self, x):
        x = self.embed(x).unsqueeze(1)  # (batch, 1, embed_dim)
        x = self.transformer(x)
        x = x.mean(dim=1)  # global average pooling
        x = self.fc(x)
        return x
\end{verbatim}

\subsection{Data Preprocessing}

\textbf{Missing values:} Column-wise mean imputation. For each feature, missing entries are replaced with the mean computed on non-missing entries in the training set. Mean is fitted on training, applied identically to test.

\textbf{Normalization (deep models only):} StandardScaler fit on training features (mean 0, std 1). Test features are transformed using training statistics to prevent leakage.

\textbf{Class balance (stratified splits):} Both random and temporal splits use \texttt{StratifiedShuffleSplit} (random) or manual stratification (temporal) to preserve label proportions (e.g., 18.3\% defects on ApacheJIT) in train and test.

\textbf{Thresholds:}
\begin{itemize}
\item ApacheJIT defect label: Commit is defective if linked to defect-fixing commit (binary: 0 or 1).
\item city\_hour PM$_{2.5}$ label: Defective if PM$_{2.5}$ > 60 μg/m³ (India AQI standard for "poor" category).
\item PROMISE defect label: Class is defective if defect count > 0 (binary: 0 or 1).
\end{itemize}

\subsection{Evaluation Metrics and Reporting}

All models output binary predictions or probabilities. Metrics are computed as follows:

\textbf{AUC:} Area under the receiver operating characteristic curve. Computed from predicted probabilities using \texttt{sklearn.metrics.roc\_auc\_score}.

\textbf{F1-score:} Harmonic mean of precision and recall, computed at probability threshold 0.5. Computed using \texttt{sklearn.metrics.f1\_score}.

\textbf{Accuracy:} Fraction of correct predictions (not reported in main tables but available in supplementary materials).

\textbf{Reported values:} Mean and standard deviation (SD) over three random seeds. Example: "0.839±0.001" means mean 0.839, SD 0.001.

\subsection{Computational Environment}

\textbf{Hardware:} NVIDIA GPU (e.g., RTX 3080, A100) or CPU fallback.

\textbf{Runtime per model:}
\begin{itemize}
\item Tree models: <1 minute per seed (ApacheJIT, city\_hour); <10 seconds (PROMISE).
\item Deep models: 5--15 minutes per seed (ApacheJIT, city\_hour); <1 minute (PROMISE).
\item Total for all models and seeds: ~8 GPU hours.
\end{itemize}

\textbf{Software versions:} Python 3.10, scikit-learn 1.3.0, xgboost 2.0.0, lightgbm 4.0.0, PyTorch 2.0, pandas 2.0, numpy 1.24.
